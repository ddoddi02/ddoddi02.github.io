## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트 | 지인용 웹 기반 멀티플레이 게임 플랫폼 |
| 기간 | 2026.11.13 ~ 2026.11.15 (3일) |
| 작업량 | 커밋 5회, 코드 약 8,300줄 |
| 형태 | 브라우저 접속형, 별도 설치 없음 |

- 카드 게임, 물리 기반 게임, 미니게임 등 여러 종류의 게임을 한 사이트에서 제공함.
- 게임 내 재화는 가상 재화이며 실제 금전과 무관함.

## 2. 기술 구성

| 구분 | 사용 기술 |
|---|---|
| 클라이언트 | HTML, CSS, JavaScript (프레임워크 미사용) |
| 서버 | Cloudflare Workers, Durable Objects |
| 데이터 저장 | SQLite (Durable Objects 내장) |
| 실시간 통신 | WebSocket |
| 물리 연산 | matter-js (서버 측 실행) |
| 운영 비용 | Cloudflare 무료 플랜 범위 내 |

## 3. 일자별 작업 내역

### 3.1 1일차 (11.13) — 초기 버전

- P2P 라이브러리를 이용해 서버 없는 구조로 첫 버전 구현.
- 다인원 카드 게임 1종과 미니게임 3종 구현.
- 인원 부족 시 참여하는 봇 기능 구현.

### 3.2 2일차 (11.14) — 서버 구조 전환 및 화면 개선

- P2P 구조를 폐기하고 Cloudflare Workers 기반 서버 구조로 전환.
- 회원 가입·로그인 및 계정 데이터 서버 저장 기능 구현.
- 게임 방 단위로 서버 객체를 분리하고 WebSocket으로 상태 동기화.
- 방장 승계, 일시적 연결 끊김 시 재접속 처리 구현.
- 게임 진행 연출(카드 분배, 베팅 애니메이션 등) 추가.

### 3.3 3일차 (11.15) — 게임 추가 및 편의 기능

- 카드 게임 1종 추가. 기존 게임의 엔진과 화면 코드를 상속해 구현.
- 물리 기반 멀티플레이 게임 2종 추가.
- 열린 방 목록 조회 및 바로 참가 기능 추가.
- 랭킹 기능 추가.
- 휴대폰·태블릿·PC 화면 대응(반응형) 작업.
- 게임 재화 정산 규칙 및 방 설정 항목 정비.

## 4. 주요 기술적 판단

| 항목 | 판단 | 사유 |
|---|---|---|
| 서버 도입 | P2P → 서버 구조 전환 | 재화 등 중요 데이터는 서버를 기준으로 관리해야 신뢰성 확보 가능 |
| 코드 재사용 | 게임 엔진 공통 구조 설계 | 신규 게임 추가 시 기존 엔진과 화면을 상속해 개발 기간 단축 |
| 물리 연산 위치 | 서버에서 계산 후 결과 전송 | 클라이언트별 연산 시 화면 불일치 발생 가능성 |
| 인프라 | Cloudflare 무료 플랜 | 소규모 인원 대상 서비스로 무료 한도 내 운영 가능 |
